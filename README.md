# MapLog

다녀온 나라와 도시를 도트 지도로 기록하는 설치형 웹앱(PWA).

기록은 브라우저의 IndexedDB에만 저장됩니다. 계정도 서버도 없습니다.

## 안드로이드 앱

Capacitor로 감싼 네이티브 앱도 같은 소스에서 나옵니다. 웹 자산을 APK 안에 담기
때문에 첫 실행부터 완전히 오프라인이고, GitHub Pages와 무관하게 동작합니다.

```bash
npm run app:apk
```

`android/app/build/outputs/apk/debug/app-debug.apk`가 나옵니다(약 5MB). 디버그
서명이라 사이드로드로 바로 설치됩니다. 스토어용 릴리스 빌드는 별도 키스토어가
필요합니다.

빌드에는 JDK 17과 안드로이드 SDK(platform 34, build-tools 34)가 필요하고,
`android/local.properties`에 `sdk.dir`을 적어야 합니다. 이 파일은 커밋하지
않으며 **경로에 백슬래시 대신 슬래시**를 써야 합니다 — Java properties에서
백슬래시는 이스케이프 문자라 경로가 깨집니다.

런처 아이콘은 `npm run data:icons`가 웹 아이콘과 같은 도트 필드로 생성해
`android/app/src/main/res/mipmap-*`에 덮어씁니다.

## 배포

`main`에 푸시하면 GitHub Actions가 빌드해서 GitHub Pages로 올립니다
(`.github/workflows/deploy.yml`). 저장소 설정에서 **Pages → Source를 GitHub
Actions**로 지정해 두어야 합니다.

프로젝트 사이트는 `/<repo>/` 하위 경로로 서비스되므로 워크플로가 저장소 이름에서
`VITE_BASE`를 만들어 넘깁니다. `<id>.github.io` 저장소인 경우에는 루트(`/`)를
씁니다. 로컬에서 하위 경로를 확인하려면:

```bash
npm run preview:pages
```

폰트는 `src/assets/fonts/`로 생성해 Vite가 해시를 붙이고 base를 반영하게 했습니다.
`public/`에 두고 절대 경로로 참조하면 하위 경로 배포에서 404가 납니다.

## 개발

```bash
npm install
npm run dev
```

지도 데이터(`public/data/`)는 저장소에 포함되어 있습니다. 국경 데이터나 격자
해상도를 바꿀 때만 다시 생성하면 됩니다.

```bash
npm run data:map -- --width 1200   # 세계 격자 + 국가 레지스트리 (약 2분)
npm run data:cities                # 국가별 도시 청크 (첫 실행 시 GeoNames 내려받음)
npm run data:icons                 # 앱 아이콘과 파비콘
```

## 지도가 그려지는 방식

`scripts/build-map-data.mjs`가 Natural Earth 국경(world-atlas 50m)을 Equal Earth
투영에 올린 뒤, 1200×584 격자의 각 칸이 어느 나라에 속하는지 미리 계산해 둡니다.

- `public/data/world-grid.bin` — 8바이트 헤더(`MLG1`, width, height) + 칸별 국가
  인덱스 `Uint8`. 원본 684KB, gzip 17KB.
- `public/data/countries.json` — 인덱스 ↔ 국가 정보(한글명, 국기, 대륙, UN 여부,
  상위 국가, 앵커 좌표).

런타임(`src/map/DotMap.tsx`)은 이 래스터를 **스트라이드 샘플링**으로 그립니다.
축소할수록 스트라이드가 2배씩 커져서 화면에 찍히는 점의 개수가 확대/축소와
무관하게 일정합니다. 점 크기도 스트라이드를 따라가므로, 확대하면 점이 흩어지는
대신 격자가 잘게 쪼개지는 것처럼 보입니다.

모든 나라는 `anchor` 칸을 하나씩 갖습니다. 모나코·바티칸·투발루처럼 격자 한 칸도
차지하지 못하는 43개국이 축소 상태에서 사라지지 않도록 하는 장치입니다.

탭 판정도 같은 래스터를 씁니다 — 화면 좌표를 격자 좌표로 바꿔 배열을 한 번
읽고, 빈 칸이면 주변을 훑어 가장 가까운 나라를 고릅니다.

## 도시 데이터

`scripts/build-city-data.mjs`가 GeoNames의 인구 15,000명 이상 도시 34,089곳을
국가별 청크로 나눕니다. 앱은 열어 본 나라의 청크만 받아 오고, 서비스워커가
`CacheFirst`로 보관해 다음부터는 오프라인에서도 열립니다. 전체 1.7MB이지만
설치 시 미리 받는 것은 `index.json`뿐입니다.

한글 도시명은 `alternateNamesV2` 덤프(202MB)에서 `isolanguage=ko` 행만 걸러
씁니다. 이름만 들어 있는 `alternatenames` 컬럼을 쓰면 언어 구분이 없어 서울이
"경성", 상하이가 "상해"로 잡힙니다. 태그가 붙은 덤프에는 `isPreferredName`과
`isHistoric`이 있어 이 문제가 없습니다. 걸러낸 결과는
`scripts/.cache/ko-names.tsv`로 남고 202MB 원본은 지웁니다 — 다시 받을 일은
`--refresh`를 줄 때뿐입니다.

도시 좌표는 지도 격자와 같은 Equal Earth 공간에 찍힙니다. `countries.json`이
투영의 scale·translate를 실어 보내고 클라이언트는 공식을 직접 계산하므로
d3-geo가 번들에 들어가지 않습니다. 빌드가 d3 결과와 1e-6px 이내로 일치하는지
매번 확인합니다.

## 사진에서 가져오기

사진을 고르면 EXIF의 GPS 좌표를 읽어 다녀온 곳을 찾습니다. **사진은 기기 밖으로
나가지 않고, 좌표만 쓰고 파일은 저장하지 않습니다.** 기록하기 전에 무엇이
잡혔는지 목록으로 먼저 보여 주고, 체크한 것만 저장합니다.

나라 판정에 지오코딩 API를 쓰지 않고 **이미 있는 세계 격자**를 씁니다 — 좌표를
투영해 칸 하나를 읽으면 끝입니다. 다만 한 칸이 약 19km라 국경 근처에서 반대편
나라가 잡힐 수 있어서(우수아이아가 칠레로 잡히는 식), 주변 칸의 나라들을 모두
후보로 모은 뒤 **가장 가까운 실제 도시가 나라를 결정**하게 했습니다. 도시 좌표는
정확하기 때문입니다.

도시 선택에는 한 가지 보정이 더 있습니다. GeoNames는 파리의 구(區)를 각각 도시로
등록해 두어서, 센강가에서 찍은 사진의 최근접 도시가 "Paris 04 Hôtel-de-Ville"이
됩니다. 그래서 최근접 지점에서 12km 안에 더 큰 도시가 있으면 그쪽을 고릅니다.

EXIF 파서(`exifr` lite 빌드, HEIC 지원)와 이 화면은 지연 로딩합니다 — 사진을
가져올 때만 받고, 그 청크도 서비스워커가 미리 캐싱하므로 오프라인에서 동작합니다.

## 오프라인과 설치

설치 시 미리 받는 것은 앱 셸 · 세계 격자 · 국가 목록 · 도시 인덱스 · 폰트까지
**1.3MB**입니다. 도시 청크 244개(1.7MB)는 열어 본 나라만 `CacheFirst`로 받아
보관합니다.

`npm run build`는 먼저 `scripts/build-fonts.mjs`를 돌립니다. Pretendard 전체는
2MB인데 대부분이 한글 11,172자이고, 이 앱의 한글은 **빌드 시점에 전부
정해집니다** — 나라·도시 이름은 생성된 데이터 파일에, 나머지는 소스에 있습니다.
그래서 실제 쓰이는 글자만 추려 **199KB(90% 감소)** 로 만듭니다. 검색창에 직접
입력한 글자가 이 범위를 벗어나면 시스템 한글 글꼴로 떨어집니다(두부 아님).

## 백업

설정 탭에서 JSON 파일로 내보내고 불러옵니다. 불러오기는 병합이 아니라
**덮어쓰기**이며, 확인 화면에 파일 이름과 들어 있는 기록 수를 먼저 보여 줍니다.
배지는 파생값이지만 획득 날짜는 사용자 기록이라 함께 담습니다.

## 배지

`src/state/badges.ts`가 배지 23개를 정의합니다. 획득 여부는 **저장하지 않고 방문
기록에서 매번 계산**합니다 — 지도의 색칠과 같은 원리라, 배지와 지도가 어긋날 수
없습니다. DB에는 획득 시각만 남고, 조건이 깨지면 그 기록도 지웁니다.

대륙 배지의 카드 그림은 세계 격자에서 잘라 낸 진짜 대륙 도트 지도입니다
(`src/map/continentGlyphs.ts`). 별도 이미지 에셋이 없습니다. 다만 대륙 경계를
그대로 쓰면 안 되는데, countries-list가 러시아를 유럽으로 분류해서 유럽의 실제
범위가 캄차카까지 가기 때문입니다. 그래서 대륙마다 사람이 기대하는 화각을
경위도 상자로 지정해 두었습니다.

지리 배지는 도시 좌표를 읽으므로, 방문한 나라의 도시 청크가 **전부** 도착하기
전에는 판정하지 않습니다(`useCityCoords`의 `ready`). 절반만 불러온 상태로
배지를 뺏거나 주지 않기 위해서입니다.

## 국기 표시

윈도우는 국기 이모지 폰트를 제공하지 않아 크롬이 🇬🇭를 "GH" 글자쌍으로 그립니다.
`src/components/FlagMark.tsx`가 캔버스에 국기를 그려 색이 나오는지 한 번 확인한 뒤,
지원하지 않으면 ISO 코드 칩으로 대체합니다. 안드로이드·iOS·macOS에서는 국기가
그대로 나옵니다.

## 국가 목록 기준

- UN 회원국 193개 + 옵서버 2개(바티칸, 팔레스타인) = **195개국**을 분모로 씁니다.
- 속령은 `scripts/data/regions.mjs`의 `PARENT_OF`에 따라 상위 국가 아래로 묶입니다.
- 코소보는 XK로 포함했습니다. 소말릴란드·북키프로스 등 ISO 코드가 없는 지역은
  땅으로 그리되 방문 대상에서는 제외합니다.
- 한글 국가명은 CLDR(`Intl.DisplayNames`)을 따르고, 홍콩·마카오만 짧게 덮어씁니다.
